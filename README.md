# 🦷 Odontolyt - Consultorio Odontológico Digital

![Odontolyt Banner](banner.png)

**Odontolyt** es una solución integral de gestión para consultorios odontológicos que combina una estética moderna y "fresca" con una arquitectura robusta y segura. Diseñada para transmitir confianza al paciente y eficiencia al profesional.

## ✨ Características Principales
- **Diseño Premium**: Basado en el sistema **Material 3** con una paleta de azules y turquesas.
- **Seguridad Avanzada**: Autenticación con **JWT** y validación de **reCAPTCHA** en frontend y backend.
- **Gestión Multi-Rol**:
  - **Administrador**: Control total de usuarios, servicios, inventario y reportes.
  - **Odontólogo**: Agenda dinámica, gestión de historias clínicas y notas de tratamiento.
  - **Paciente**: Reserva de citas online, historial de tratamientos y gestión de documentos.
- **Responsivo**: Adaptado para tablets, móviles y escritorio.

## 🛠️ Tecnologías Utilizadas
- **Frontend**: ReactJS (Vite), HTML5, CSS3 (Vanilla).
- **Backend**: Java Spring Boot 3, Spring Security, JWT.
- **Base de Datos**: Supabase (PostgreSQL).
- **Seguridad**: Google reCAPTCHA, BCrypt.

## 📁 Estructura del Proyecto
- `/frontend`: Aplicación cliente en React.
- `/backend`: API REST en Spring Boot.
- `/database`: Scripts SQL para la base de datos.
- `/docs`: Documentación técnica y académica.
